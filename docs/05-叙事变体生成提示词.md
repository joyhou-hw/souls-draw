# 05-叙事变体批量生成提示词（外部模型调用手册）

> **用途**：本文档分两部分。第一部分是给操作者（你）的工作流说明；第二部分是可直接复制给任意外部大模型的**提示词主体**，用于批量生成《生灵引·罗小黑战记》叙事文本库的长尾变体。
>
> **分工总览**：schema 与校验器由开发侧完成（T3.1 已收官）；打样种子库（约 35 条"金标准"）已写入 `spirit/worlds/luoxiaohei/narratives.yaml` 定调文风；剩余 1,500–3,000 条长尾变体由外部模型按本文档提示词批量产出；回流后由 dsl 校验器自动把关（格式/槽位/id 重复/桶值域四道闸）。

---

## 一、操作者工作流

1. 复制下方【提示词主体】全文（从"你是一名"开始到"输出前自检"结束）。
2. 在其后追加**本批任务**——从文末【批量任务分配表】复制对应批次行，例如：
   ```
   本批任务：为事件 quiet_year 的 fallback 生成 40 条变体，id 前缀 qy_f，编号 02 起。
   ```
3. 外部模型输出的 YAML 块，粘贴进 `spirit/worlds/luoxiaohei/narratives.yaml` 对应事件的 `fallback:` 或桶的 `variants:` 列表末尾。
4. 运行回流闸门（罗小黑真实包全量校验，含新增内容）：
   ```
   cd spirit
   node --test "packages/dsl/src/narratives.test.ts"
   ```
   任何格式错误、未知槽位、id 重复、桶枚举越界都会被拒并给出字段路径，按报错修正即可。
5. 建议每批 ≤ 60 条，多轮分批回填，避免单次生成质量稀释。

**变体 id 全局唯一是铁律**（不放回抽样的键）：跨批次生成时，务必在任务里指定"编号 N 起"（打样库已占用 01–05 号段），避免撞车。

## 二、提示词主体（复制以下全文给生成模型）

你是一名中文叙事文案写手，为"人生模拟"游戏《生灵引》的罗小黑战记世界包批量生成叙事文本变体。你的输出将被机器直接解析进 YAML 文本库，**格式合规比文采更优先**。

### 世界观速览

- 舞台：人与妖精共存的东方幻想世界。妖精化形为人生活在城市与会馆中；灵质（妖精的灵力本源）与灵气（环境能量）是世界的暗流。
- 视角：**第二人称"你"**——你扮演一个刚出生的小生命（可能是人类，也可能是动物妖、植物妖、真菌妖、器物妖、先天灵体），从出生走完由灵质收支决定的一生：凡人劳损灵质易早衰，妖精寿长可活百余年乃至更久。
- 基调：小人物的烟火气人生。克制、白描、留白；妖精视角下的人类都市既疏离又亲切。参考《罗小黑战记》的温和日常 + 轻奇幻质感。

### 输出格式铁律（违反任何一条即被机器拒收）

1. **变体一律块式两行写法**，禁止流式单行 `{id: …, text: …}`：
   ```yaml
   - id: qy_f_06
     text: 平静的一年，檐下听雨。
   ```
2. **只用全角标点**（，。、；：？！——…），**严禁**半角 `: , } ] #` 与任何引号（" ' " '）出现在文本中。
3. 文本中若需占位，**只用这四个槽位**（花括号包裹，渲染时自动替换为该人生的实际值）：
   - `{place}` —— 地区：森林 / 城市 / 会馆领地 / 隐修岛
   - `{species}` —— 你这一世的形态
   - `{niche}` —— 你这一世的营生/生态位
   - `{era}` —— 时代：古代 / 现代
   除此之外的花括号一律非法。**能泛化就泛化**：写"你在{place}度过一年"而非写死"你在森林度过一年"。
4. **变体 id 规范**：`<事件缩写>_<桶标记>_<序号>`，全小写蛇形。事件缩写与桶标记见本批任务说明；序号两位数字。**id 全局唯一**，同批内不重复，跨批按任务给定的起始编号续排。
5. **text 单条长度 15–40 字**，一或两个短句，句号结尾。
6. 每条变体是**独立的叙事原子**：不与其它变体构成上下文连续剧（渲染时随机拼接、随机组合，任何顺序出现都必须通顺）。
7. 文风总则：白描 + 一处具体意象（檐雨、灯影、衣角、土腥、纸页……）；禁华丽辞藻堆砌，禁排比，禁感叹号连用，禁网文腔；**不要**写"这一年你感到无比幸福"这类直陈情绪——写"灶上汤一直温着"让读者自己感到。

### 文风校准样例（金标准，模仿其克制度）

```yaml
- id: qy_f_01
  text: 平静的一年，无风也无浪。
- id: qy_h_01
  text: 你在人群中过着寻常的一年，没人知道你知晓妖精的存在。
- id: gr_f_01
  text: 会馆的名册翻到你这一页，墨迹未干。
- id: op_01
  text: 这一年{place}的雨季来得早，
- id: cl_01
  text: 你把这一年收进心里，像收一颗温热的石子。
```

### 抉择事件的 prompt（仅指定时）

抉择事件的 `prompt` 是**单条提示语**（不是数组），需含一个明确问句（玩家将二选一），例：
```yaml
prompt: 会馆名册翻到你这一页，墨迹未干。穿制服的妖精师向你伸出橄榄枝。加入会馆吗？
```

### 输出前自检（逐条核对后再输出）

- [ ] 全部为块式两行变体，无一字流式
- [ ] 全角标点，无半角 `: , } ] #`，无任何引号
- [ ] 花括号只出现 {place} {species} {niche} {era} 四种
- [ ] id 前缀与本批任务一致，序号连续且不与既有重复
- [ ] 每条 15–40 字，"你"视角，句号收尾
- [ ] 相邻变体意象不雷同（同意象在不同批次复用率 < 三成）

输出时只输出 YAML 变体块本身，不要额外解释、不要代码围栏、不要总结。

**B7 碎片规范**：openers 为**不完整短句**（逗号或破折号收尾，如"这一年{place}的雨季来得早，"），closers 为可缀于任何年叙事后的收束短句。两者都须与任意事件句拼接后通顺。

**B8 题注规范**：照片式两行短题注（第一行场景，第二行留白式点睛），如：
```yaml
- id: ms_sft_01
  text: 化形那夜的你——{place}，月光正好。
```

**编号占用现状**：打样种子库已占用各事件 01–05 号段（部分事件仅 01–02）。新批次一律从任务指定的起始号续排，操作者按 narratives.yaml 现有最大号 +1 通知生成模型。
