## 1. 四部作品力量体系速查

### 1.1 西游记 —— 编制式神魔

| 梯队 | 层级 | 代表人物 |
|---|---|---|
| T0 | 天道级 | 三清、菩提祖师 |
| T1 | 圣尊级 | 如来、镇元子、观音、弥勒 |
| T2 | 战神级 | 孙悟空、二郎神、牛魔王、六耳猕猴、大鹏 |
| T3 | 法宝/神通特殊级 | 青牛精（金刚琢）、黄眉（金铙）、红孩儿（三昧真火） |
| T4 | 常规妖王 | 各洞主、山君 |

**核心逻辑**：境界 ＞ 神通 ＞ 法宝 ＞ 势力。

**加权评估公式**（粉丝社区量化模型）：

```
综合战力 = 位阶×2.0 + 法宝×1.3 + 神通×1.2 + 防御×1.0 + 武艺×0.8 + 速度×0.7
```

**编制效应**："编制内 ＞ 野生"——天庭/灵山在编者有法宝配发、有背景靠山；野生妖王靠肉身硬扛。取经路上"没背景的妖怪打死，有背景的被收编"即是此逻辑的叙事化。

### 1.2 全职法师 —— 觉醒式魔法

| 维度 | 体系 |
|---|---|
| 法师境界（6级） | 学徒 → 初阶 → 中阶 → 高阶 → 超阶 → 禁咒 |
| 魔法结构（7级） | 星子 → 星轨 → 星图 → 星座 → 星宫 → 星宿 |
| 觉醒机制 | 16岁觉醒第一系；随机觉醒；雷系最难（约 1/1000） |
| 妖魔等级（5级） | 奴仆 → 战将 → 统领 → 君主 → 帝王 |
| 双系/多系 | 高阶法师可觉醒第二系；禁咒法师需双系精通 |

## 2. 共性支柱提炼：五大支柱

四部作品表面差异极大（神魔 / 都市魔法 / 忍者 / 修仙），剥掉皮之后是同一副骨架：

| # | 支柱 | 西游记 | 全职法师 | 火影 | 凡人 | **罗小黑现状** |
|---|---|---|---|---|---|---|
| P1 | **能量源**（资源池） | 法力/仙气 | 魔力（星子） | 查克拉 | 法力 | 灵力（有，未量化） |
| P2 | **境界阶梯**（离散台阶+突破事件） | 五梯队 | 6级 | 影级（下忍→上忍→影） | 13级 | 无显式阶梯（弱） |
| P3 | **系别分化**（横向差异） | 五行/神通 | 雷火冰暗等 | 五行性质变化 | 五灵根 | **七灵系（强）** |
| P4 | **硬门槛**（不可后天习得） | 法宝靠编制 | 雷系觉醒难 | **血继限界** | 灵根资质 | **空间系不可后天习得（已同构）** |
| P5 | **组织修正**（势力加成） | **编制内＞野生** | 学院/协会 | 忍村 | 宗门 | **会馆籍 vs 黑户（已同构）** |

**关键发现**：罗小黑在 P3（灵系分化）、P4（硬门槛）、P5（组织修正）三根支柱上已经与四大名著**天然同构**——

- 空间系不可后天习得 ≙ 火影"血继限界"（血缘传承、稀缺轴、双灵质≈瞳术级稀缺）
- 会馆籍 vs 黑户 ≙ 西游"编制内 vs 野生"（老幺/无限有会馆资源与身份庇护；风息是黑户，无组织靠山）
- 七系权重 ≙ 全职法师觉醒概率 + 火影性质变化（御灵0.50像"常见系"，空间0.01像"雷系1/1000"）

**短板**：P1（灵力未量化）、P2（无境界阶梯）——这正是"合并"可以补的两块。

## 5. 灵力量化表 v0.3 提案

> **总原则**：只吸收凡人"全档量化"的**方法**，不吸收其**数值跨度**。罗小黑最强者（无限级）与最弱者的灵力量级差距 ≈ 10³，不是凡人的 10⁸。
>
> 标注 ⚠ 者为推定（原作无显式数值，按剧情表现推定）。

### 5.1 灵力阶梯（6档）

| 档 | 名称 | 判定（推定自原作表现） | 突破事件（引擎事件） | 代表 |
|---|---|---|---|---|
| L0 | **凡体** | 灵力未显性或微量 | 灵力显性掷骰（01 §7.1.1 闸1） | 普通人、未修行小妖 |
| L1 | **凝形** ⚠ | 可稳定维持人形/原型态；能御使小物 | 凝形事件（前置链阶段2收尾） | 谛生期小妖、小黑初登场 |
| L2 | **御物** ⚠ | 熟练单灵系应用；御物飞行 | 单系大成事件 | 会馆普通执行者 |
| L3 | **灵域** ⚠ | 展开领域/多系协同；城市级感知 | 灵域展开事件（常伴入口事件） | 比丘、阿根级 |
| L4 | **大妖** | 战略级；空间系在此档才显威（若持有） | 大妖认可事件（会馆授勋/独修悟道） | 无限、风息、潘靖 |
| L5 | **圣灵** ⚠ | 半步升仙；炼丹造物级 | 契机事件（天明珠级物品/老君点化） | 老君 |
| — | **升仙** | 脱离本世界模拟（终点之一） | 升仙事件（结局触发器） | 无限的目标 |

- 境界是**引擎内部量**：原作世界里没有公开等级社会（无人自称"L3"），阶梯只用于事件门槛与叙事描述对齐——这与凡人"境界社会化"的关键差异。
- L4→L5 与 L5→升仙 都走**契机事件**而非累积突破——保持罗小黑"升仙靠机缘"的原味（B4）。
