## 3. 格式铁律速查（每批回流前自检）

1. 变体一律块式两行：`- id: ...` 换行 `text: ...`，禁止流式 `{...}`。
2. 只用全角标点；严禁半角 `: , } ] #` 与任何引号。
3. 槽位仅四种：`{place}` `{species}` `{niche}` `{era}`；其余花括号非法。
4. 变体 id 全小写蛇形 `<事件缩写>_<桶标记>_<序号>`，全局唯一（不放回抽样键）。
5. text 单条 15–40 字，"你"视角，句号收尾。
6. 文风：白描 + 一处具体意象；禁直陈情绪；独立叙事原子，不与相邻变体构成连续剧。
7. 回流闸门：`cd spirit && node --test "packages/dsl/src/narratives.test.ts"`。
